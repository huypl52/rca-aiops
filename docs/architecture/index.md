# Architecture and Planning Docs

This section groups design-time and future-shape material so it does not compete with current-runtime/operator docs.

## Use these docs when

- you need historical architecture context
- you need future LLM/runtime direction
- you are planning changes to the RCA graph or planner seam

## Files

- `docs/PROJECT_SPECS.md` — original project/foundation spec
- `docs/architecture/llm-insertion-plan-for-rca-runtime.md` — target insertion plan for LLM-backed reasoning
- `docs/architecture/llm-hypothesis-planner-runtime-profile.md` — hypothesis-planner runtime profile

## Important distinction

These docs are **not** the canonical statement of current runtime behavior.

For what is true in the running system today, use:
- `docs/current-rca-runtime-truth-table.md`
- `docs/integration/index.md`
- `docs/operator-runbook.md`
